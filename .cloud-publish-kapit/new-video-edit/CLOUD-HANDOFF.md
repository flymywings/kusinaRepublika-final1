# New video edit — cloud handoff

This directory contains the source, supporting assets, audio, and workflow documents copied from the local `new video edit` workspace.

Start with `docs/creative-orchestration.md`, `supermarket-after-hours/BUILD.md`, and `supermarket-after-hours/approved/v8-acceptance.json`. The supermarket V8 film is the accepted baseline; preserve the recorded approvals. Other folders contain earlier shorts, experiments, references, and reusable production tools.

Install JavaScript dependencies from this directory with `npm ci`. Inspect each project's existing render and check scripts before running it. Local Windows paths in older scripts may need adjustment for Linux; this upload does not assert cloud rendering has been validated.

Generated MP4 renders, dependency installations/caches, diagnostics, Python bytecode, packaged dependencies, logs, and numerical/tracking intermediates were omitted. The original files remain on the PC. Render outputs mentioned in acceptance records are historical evidence and are not included here; regenerate them from source when needed. Source reference videos were also omitted by the MP4 exclusion.

The repository's pre-existing root application is preserved. Work in `new-video-edit/` for the animation project.
